Getting started
Connect your Agent to Yabane
Use Yabane as the API Provider in your coding Agent, then select a Yabane model ID.

    

      

      

      

      
Pi reads custom providers from ~/.pi/agent/models.json. Save the generated config there, export the Gateway key, then run pi.
The model ID includes Yabane’s provider/model prefix. Pi uses yabane as the configured provider name and preserves the model ID for Yabane routing.

      
Save this as opencode.json, export the key, then run opencode.

      
Claude Code can use Yabane's Anthropic Messages surface. Yabane will use an Anthropic Endpoint when available, or explicitly convert the request to the selected compatible Endpoint.

      
Codex CLI supports a custom Responses API provider in ~/.codex/config.toml. Yabane prefers an OpenAI Responses Endpoint and can explicitly convert the request to another configured protocol when required.

      
VS Code Copilot’s stable settings do not provide a generic custom OpenAI/Anthropic base URL. Its model picker is tied to Copilot or installed extensions, so Yabane cannot generate a reliable settings.json entry for it.
Use the Generic Agent values if you have a VS Code extension that supports custom providers, or use the dedicated Pi, OpenCode, Claude Code, or Codex configuration above.
